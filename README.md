# WEDDING QUEST — 우신범 ♥ 김한아 모바일 청첩장

## 폴더 구조
```
index.html      뼈대(HTML)
style.css       디자인/애니메이션
script.js       상호작용(캘린더, 갤러리, 방명록, 복사 등)
images/         교체 가능한 이미지 리소스
  bg-castle.png        히어로 배경 (하늘+성, 고정)
  bg-castle-wide.png   푸터 배경 (하늘+성, 가로형)
  clouds.png           구름 (좌→우 무한 스크롤)
  ground.png           땅/풀 (좌→우 무한 스크롤, 구름보다 빠름)
  title-logo.png        타이틀 로고 ("신범♥한아 결혼식")
  date-ribbon.png       날짜 리본 배너
  flower-divider.png    섹션 사이 꽃 구분선
  gallery-frame.png     (선택) 갤러리 사진 액자 테두리 — 없어도 정상 작동
  gallery/
    photo1.jpg ~ photo9.jpg   갤러리 사진 9장
  petals/
    petal1.png ~ petal4.png   흩날리는 꽃잎 이미지 4종
```

## 이미지 교체 방법
`images/` 폴더의 파일을 **같은 파일명**으로 덮어쓰기만 하면 됩니다.
코드를 건드릴 필요가 없습니다.

### 히어로 배경(bg-castle.png) 크기는 내가 직접 정해도 됩니다
`bg-castle.png`는 이제 `<img>` 태그로 삽입되어 있어서, 히어로 섹션 전체 높이가
**이 이미지의 실제 세로 길이를 그대로 따라갑니다.** 코드를 고칠 필요 없이
파일만 새 크기로 바꿔 넣으면 자동으로 반영됩니다.

- **가로 폭**: `460px` 를 권장합니다. 구름/땅/로고/리본 이미지가 전부 460px 폭
  기준으로 만들어져 있어서, 배경도 같은 폭으로 맞추면 서로 어긋나지 않습니다.
- **세로 길이**: 정해진 값은 없습니다. 원하는 만큼 길게/짧게 만들어도 됩니다.
  다만 그 안에 배치되는 로고·캐릭터·리본 위치는 `style.css`에서
  히어로 높이에 대한 **비율(%)**로 잡혀 있어서, 세로 길이를 크게 바꾸면
  아래 값들의 상대적 위치(간격)도 함께 조정해야 자연스럽습니다.
  - `.title-logo-img { top: 7%; }`
  - `.sprite-row { top: 58%; }`
  - `.ground-layer { bottom: 14%; height: 17%; }`
  - `.date-ribbon-img { top: 85%; }`
  - `.press-start { top: 95%; }`
  참고용 기준값: 원본 목업 비율은 가로 460px 기준 세로 약 **780~980px** 사이였습니다.
  이 범위면 별도 조정 없이도 무난하게 어울립니다. 그보다 훨씬 길게 만들 경우
  위 % 값들을 조금씩 조정해 주세요.
- `clouds.png`, `ground.png` 는 좌우로 이어붙여 스크롤되므로 좌/우 끝이
  자연스럽게 맞물리는 이미지일수록 이음새가 티가 덜 납니다.
- `title-logo.png`, `date-ribbon.png` 는 투명 배경 PNG를 권장합니다.

## 이미지 갤러리 (OUR STORY)
"결혼식 날짜"와 "오시는 길" 사이에 사진 9장 캐러셀이 들어갑니다.
- 좌우 화살표 버튼, 좌우 드래그(스와이프), 하단 점(dot) 클릭으로 이동 가능
- 9번째 사진에서 다음으로 넘기면 1번째로 순환
- 사진을 탭하면 배경이 하얗게 흐려지며 사진이 크게 확대됩니다 (다시 탭하면 닫힘)

### 사진 교체
`images/gallery/photo1.jpg` ~ `photo9.jpg` 를 같은 파일명으로 덮어쓰세요.
- 정사각형에 가까운 비율 권장 (예: 800×800px 이상)
- 원본 비율이 달라도 정사각형 틀에 꽉 차게 자동으로 잘려서 보입니다(`object-fit: cover`)

### 액자 테두리 이미지 (선택)
보내주신 예시(이미지1)처럼 나무 액자 테두리를 사진 위에 씌우고 싶다면
`images/gallery-frame.png` 파일을 추가하세요. 파일이 있으면 자동으로 적용되고,
없으면 테두리 없이 사진만 깔끔하게 보입니다 (에러 없이 자동 처리됨).

**권장 규격**
- 캔버스 크기: **정사각형 640×640px** (고해상도라 축소 표시해도 선명합니다)
- 가운데 투명 구멍: **약 500×500px**, 정중앙 정렬 (사진이 보이는 부분)
- 나머지 약 70px 두께 테두리 부분에 픽셀아트 액자 디자인
- 배경은 반드시 투명 PNG


### 맨 아래(푸터) 이미지
이전 버전에서 맨 아래에 성/하늘 이미지를 재사용해 어색했던 부분은
기본 크림색 배경으로 바꿨습니다. 나만의 엔딩 이미지를 쓰고 싶다면
`images/footer-bg.png`(원하는 크기로 자유 제작)를 추가한 뒤
`index.html`의 `<div class="footer">` 에 아래처럼 한 줄만 넣어주세요.
```html
<div class="footer" style="background-image:url('images/footer-bg.png');">
```

## 꽃잎 파티클 효과
청첩장 폭(최대 700px) 안에서만 오른쪽에서 왼쪽으로 바람에 실려가듯
살랑살랑 흔들리며 떨어지는 장식 효과입니다. 브라우저 창이 그보다 넓어도
꽃잎은 항상 청첩장이 보이는 가운데 영역 안에서만 흩날립니다(양옆 빈 공간 낭비 없음).
- 총 12개가 화면에 랜덤한 위치/속도(바람 세기)/흔들림으로 무한 반복됩니다.
- 클릭/터치를 막지 않도록(`pointer-events:none`) 처리되어 있어 버튼이나 갤러리 조작에 영향 없습니다.
- `transform`/`opacity` 만 사용하는 CSS 애니메이션이라 매우 가볍고,
  기기가 "화면 흔들림 줄이기(prefers-reduced-motion)"를 설정한 경우 자동으로 꺼집니다.

### 꽃잎 이미지 교체
`images/petals/petal1.png` ~ `petal4.png` 4장을 같은 파일명으로 덮어쓰면 됩니다.
- 권장 규격: 정사각형에 가깝게 **60×60px 내외**, 투명 배경 PNG
- 4장을 랜덤하게 섞어서 사용하므로, 색상/모양이 조금씩 다른 4가지 버전으로
  준비하시면 더 자연스럽습니다 (예: 진분홍/연분홍/크림/노랑 꽃잎)
- 개수를 조정하고 싶다면 `script.js`의 `PETAL_COUNT` 숫자만 바꾸면 됩니다
  (기본값 12, 숫자가 클수록 화려하지만 저사양 기기 부담이 늘어나니 20개 이하를 권장합니다)
- 흩날리는 가로 폭을 바꾸고 싶다면 `style.css`의 `.petal-layer`에 있는
  `max-width:700px` 값만 수정하면 됩니다.


## 배경 애니메이션 동작 방식
- `hero-bg` (하늘+성) : 고정, 움직이지 않음
- `clouds-layer` : `clouds.png`를 두 장 이어 붙여 48초 주기로 좌→우 무한 스크롤
- `ground-layer` : `ground.png`를 두 장 이어 붙여 16초 주기로 좌→우 무한 스크롤 (패럴럭스 효과)

속도를 바꾸려면 `style.css`의 `.cloud-track`, `.ground-track`의
`animation` 시간 값(예: `48s`, `16s`)만 수정하면 됩니다.

## ⚠️ 방명록 저장에 대해 (배포 전 꼭 확인)
GitHub Pages는 정적 호스팅이라 서버가 없어서, 현재 코드는
**브라우저의 localStorage**에 저장하도록 되어 있습니다.
→ 하객이 남긴 방명록은 **그 하객의 브라우저에만** 남고,
신랑신부나 다른 하객에게는 보이지 않습니다. (연습/데모용으로는 충분)

실제로 모든 하객의 방명록을 한곳에서 모아보려면 아래 중 하나를 연결해야 합니다.
- Google 스프레드시트 + Apps Script 웹앱 (무료)
- Firebase Firestore (무료 티어)

연결 시 `script.js`의 `loadList()` / `saveList()` 두 함수 내부만
해당 서비스로 데이터를 보내고 받도록 바꾸면, 나머지 코드는 그대로
사용할 수 있습니다. 원하시면 이어서 연동 코드를 작성해 드릴 수 있어요.

## 카카오페이 송금 링크 연결하기
"마음 전하실 곳"의 각 계좌 옆 **카톡송금** 버튼은 계좌 6개 모두
`index.html` 안에 `여기에_카카오페이_송금링크` 라는 placeholder로 들어가 있습니다.
아래 순서로 각자 본인의 링크를 받아서 그 자리에 붙여넣어 주세요.

1. 카카오톡 앱 → **카카오페이** → **송금** → **송금 요청/링크 받기**(또는 "나에게 돈받기") 메뉴에서 개인 송금 링크 생성
2. `index.html`에서 `여기에_카카오페이_송금링크` 문자열을 찾아 해당 인물의 실제 링크로 교체 (총 6곳: 신랑, 신랑父, 신랑母, 신부, 신부父, 신부母)
3. 링크를 넣지 않은 상태로 버튼을 누르면 "링크를 먼저 등록해 주세요" 안내만 뜨고 이동하지 않으니, 실수로 깨진 링크가 열릴 걱정은 없습니다.

## GitHub Pages 배포 방법
1. 새 저장소 생성 후 이 폴더(`index.html`, `style.css`, `script.js`, `images/`)를 그대로 업로드/push
2. 저장소 Settings → Pages → Branch를 `main`(또는 `master`) / `root`로 설정
3. 몇 분 후 `https://아이디.github.io/저장소이름/` 으로 접속 가능
